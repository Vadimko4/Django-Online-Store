# Проект "Django-Online_Store"

## Описание:

Проект является серией домашних работ к шестому модулю обучающего курса Skypro "Профессия Python-разработчик".
Посвящён работе с фреймворком Django. В нём разрабатывается интернет-магазин. 

## Структура интернет-магазина

На данный момент сайт состоит из 2-х связанных между собой страниц:
Home - домашняя
Contacts - контакты

## Техническая реализация:

Это Django-Проект. На данный момент в нём одно приложение под названием catalog.
Оно зарегистрировано в настройках проекта и для него настроена маршрутизация, добавлением соответствующих URL-адресов:
/ или home/ - рендерит домашнюю страницу
contacts/ - страницу контактов

HTML-шаблоны для домашней страницы и для страницы с контактной информацией написаны на html и css. Для их стилизации
использовался Bootstrap UI kit. В проекте настроена работа со статическими файлами. В частности необходимые для работы 
Bootstrap файлы лежат в папке static в корне проекта. 

Для отображения страниц написаны контроллеры home и contacts - в файле views.py
Для них настроена маршрутизация.


## Установка:

1. Клонируйте репозиторий:
```
git clonegit@github.com:Vadimko4/Django-Online-Store.git
```
или
```
git clone https://github.com/Vadimko4/Django-Online-Store.git
```

2. Установите зависимости:
```
poetry install
```
3. Ознакомьтесь с инструкцией в файле .env.example и донастройте окружение (django secret_key)

## Использование:

Поднимите сервер командой: 
```
python manage.py runserver
```
